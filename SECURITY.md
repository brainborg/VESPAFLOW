# Security Policy

## Supported Versions

VespaFlow is currently in early development. Security updates apply to the latest commit on `main`.

| Version | Supported |
|---------|-----------|
| 0.1.x (latest) | ✅ |
| < 0.1.0 | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in VespaFlow, please report it responsibly:

**Email:** security@vespaflow.dev  
**GitHub:** Open a [private security advisory](https://github.com/brainborg/VESPAFLOW/security/advisories/new)

You can expect an acknowledgement within 48 hours and a status update within 7 days.

## Responsible Use

This tool is designed for legitimate DevSecOps use in CI/CD pipelines you own or are authorized to remediate. Do not use VespaFlow against systems you do not own or have explicit permission to test.
